## 1. 测试范围与方法

- **工具**：Apifox 接口测试工具
- **方法**：Apifox 导入 `http://127.0.0.1:8000/openapi.json` 自动生成接口 → 配置环境 baseUrl → 逐接口发送请求，校验状态码与 `{code,msg,data}` 响应体
- **覆盖**：32 条路径（业务 31 + 根路径）的功能正确性、参数校验（422）、错误分支（400/404）、级联删除
- **说明**：系统无鉴权（教学演示），无需登录态/token；前端页面交互通过浏览器手动验证

## 2. 验证环境

- Windows，Python 3.14（.venv），FastAPI 0.141 / pydantic 2.13 / pymysql 2.2 / pydantic-settings 2.15
- MySQL 8.0（127.0.0.1:3306，school_db）
- 服务启动方式：`uvicorn main:app`（http://127.0.0.1:8000）
- 测试工具：Apifox

## 4. 接口验收结论

- 5 个业务模块接口与《接口设计说明书》清单一一对应
- `/students/page` 支持 keyword/page/page_size，返回 `{total, items}`
- 各 `xxx/all` 支持 `?keyword=` 名称模糊查询
- 级联删除逐条执行，删除后关联记录清理正确
