## 1. 概述

本手册指导用户使用 EAMS 系统：注册登录、查看首页统计、完成学生/教师/课程/班级管理与教务绑定操作。

## 2. 登录与注册

### 2.1 登录
1. 浏览器打开 `http://127.0.0.1:8000`（或由系统管理员提供地址）
2. 输入用户名、密码，点击「登 录」
3. 登录成功后自动进入后台首页

### 2.2 注册（学生）
1. 登录页点击「去注册」
2. 填写用户名（3-20 位）、密码（6-20 位）、姓名、性别、年龄（10-100）
3. 点击「注 册」，成功后返回登录页登录

> 表单必填与范围由系统校验，空/非法输入会给出中文提示。

## 3. 后台首页

登录后进入首页面板，显示：
- 欢迎语（当前用户名 + 角色）
- 统计卡片：学生总数 / 教师总数 / 课程总数 / 班级总数

左侧边栏可切换：首页 / 学生管理 / 教师管理 / 课程管理 / 班级管理；右上角可「退出」。

## 4. 学生管理

| 操作 | 步骤 |
|------|------|
| 查询 | 顶部输入「按姓名搜索」→ 点「查询」；「重置」清空回到第 1 页 |
| 分页 | 底部「上一页 / 下一页 / 页码」翻页 |
| 新增 | 点「新增学生」→ 弹框填姓名/性别/年龄/年级（可指定班级/教师）→ 确定 |
| 编辑 | 行内「编辑」→ 弹框预填修改 → 确定 |
| 分班 | 行内「分班」→ 弹框下拉选择班级 → 确定 |
| 选老师 | 行内「选老师」→ 弹框下拉选择教师 → 确定 |
| 删除 | 行内「删除」→ 确认 → 连带清理选课记录与账号 |

## 5. 教师管理

- 「按姓名搜索」查询 / 重置
- 「新增教师」弹框录入姓名、性别、年龄、科目、电话
- 行内「编辑」修改、「删除」确认删除

## 6. 课程管理

- 「按课程名搜索」查询 / 重置
- 「新增课程」弹框录入课程名、学分（1-10）、授课教师
- 行内「编辑」修改、「删除」删除课程（连带选课记录）
- 行内「选课」→ 弹框下拉选择学生 → 确定（同一课程不能重复选给同一学生）
- 「查看学生选课」→ 弹框下拉选择学生 → 展示该学生已选课程

## 7. 班级管理

- 「按班级名搜索」查询 / 重置
- 「新增班级」弹框录入班级名、年级、班主任（下拉）
- 行内「编辑」修改、「删除」删除班级

## 8. 退出登录

点击右上角「退出」，系统清除登录状态并返回登录页。

## 9. 常见问题

| 问题 | 说明 |
|------|------|
| 无需登录即可访问后台 | 系统无鉴权（教学演示），直接进入即可 |
| 操作后列表未更新 | 刷新页面或重新点击对应管理菜单 |
