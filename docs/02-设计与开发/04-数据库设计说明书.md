## 1. 概述

数据库：`school_db`，字符集 `utf8mb4`。建表脚本见项目根 `init.sql`，共 6 张表。

## 2. 表结构

### 2.1 users 用户表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INT | PK AUTO_INCREMENT | 用户 ID |
| username | VARCHAR(50) | NOT NULL UNIQUE | 用户名（登录账号） |
| password | VARCHAR(100) | NOT NULL | 密码（明文存储，教学演示） |
| role | VARCHAR(20) | DEFAULT 'student' | 角色：student / admin |
| student_id | INT | - | 关联学生 ID（学生角色时使用） |
| create_time | DATETIME | DEFAULT CURRENT_TIMESTAMP | 创建时间 |

### 2.2 teachers 教师表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INT | PK AUTO_INCREMENT | 教师 ID |
| name | VARCHAR(50) | NOT NULL | 姓名 |
| gender | VARCHAR(10) | - | 性别 |
| age | INT | - | 年龄 |
| subject | VARCHAR(50) | - | 教授科目 |
| phone | VARCHAR(20) | - | 联系电话 |
| create_time | DATETIME | DEFAULT CURRENT_TIMESTAMP | 创建时间 |

### 2.3 classes 班级表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INT | PK AUTO_INCREMENT | 班级 ID |
| name | VARCHAR(50) | NOT NULL | 班级名称 |
| grade | VARCHAR(20) | - | 年级：高一/高二/高三 |
| head_teacher_id | INT | - | 班主任教师 ID |
| create_time | DATETIME | DEFAULT CURRENT_TIMESTAMP | 创建时间 |

### 2.4 students 学生表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INT | PK AUTO_INCREMENT | 学生 ID |
| name | VARCHAR(50) | NOT NULL | 姓名 |

### 2.5 courses 课程表

| 字段 | 类型 | 约束 | 说明 |

| teacher_id | INT | - | 授课教师 ID |

### 2.6 student_course 选课表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INT | PK AUTO_INCREMENT | 选课记录 ID |
| student_id | INT | NOT NULL | 学生 ID |
| course_id | INT | NOT NULL | 课程 ID |
| score | DECIMAL(5,2) | - | 成绩 |
| create_time | DATETIME | DEFAULT CURRENT_TIMESTAMP | 选课时间 |
| （联合） | - | UNIQUE (student_id, course_id) | 同一学生同一课程只能选一次 |

## 3. 表间关系

```
users (1) ── 关联 ──> (1) students
teachers (1) ── 班主任 ──> (0..n) classes
teachers (1) ── 归属 ──> (0..n) students
teachers (1) ── 授课 ──> (0..n) courses
students (1) ── 选课 ──> (n..m) courses   (通过 student_course 中间表)
```

## 4. 关键约束与设计

- `users.username` 唯一索引；`users.role` 区分 admin / student
- `student_course` 联合唯一键 `(student_id, course_id)` 防重复选课
- `courses.credit` 默认 1
- **级联删除**（逐条执行）：
  - 删学生：`student_course` → `users` → `students`
  - 删课程：`student_course` → `courses`
- 关联查询（JOIN）：学生列表 LEFT JOIN classes/teachers 取班级名、教师名、选课数子查询
